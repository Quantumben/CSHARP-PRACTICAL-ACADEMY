Student Gradebook

Combine loops, collections, LINQ and formatting.

Your assignment: Enter students with multiple scores, compute mean and grade and display leaderboard.
Acceptance tests: Handle 0 students and invalid marks, and ensure descending sort.

Real-world brief

You have been hired to deliver a working first version. The assessor will test not only the happy path, but also invalid input, boundary values and repeat requests. Provide a README explaining setup and decisions.

Milestone 1 · Plan your design

  1. Write down the users, their actions, and the expected results.
  2. Identify domain models, fields, valid states, and validation rules.
  3. Decide where data will live: memory, JSON file, or SQLite.
  4. Write at least five test cases before implementation.

Milestone 2 · Implement the happy path

Make one end-to-end action work before creating menus, controllers or a dashboard. Keep each responsibility in a small, named method or class.

Milestone 3 · Handle failures

Handle 0 students and invalid marks, and ensure descending sort. Add validation, helpful errors, and explicit handling of missing records.

Milestone 4 · Test and explain

Show screenshots or console output for successful and rejected actions. Include dotnet build results; for tests, execute dotnet test.

Working reference implementation · starter version

This is a small runnable starting solution, not the complete project. Attempt the brief first, then compare your approach. For larger requirements, extend the starter with persistence, modular design, tests and UI.

C#
var grades = new Dictionary<string, List<int>>
{
    ["Ada"] = [70, 80, 90],
    ["Tobi"] = [45, 65, 75],
    ["Zara"] = [100, 95, 95]
};
foreach (var entry in grades.OrderByDescending(x => x.Value.Average()))
{
    if (entry.Value.Any(s => s is < 0 or > 100))
        throw new InvalidOperationException("Invalid score.");
    double average = entry.Value.Average();
    string grade = average >= 70 ? "A" : average >= 60 ? "B" : average >= 50 ? "C" : "F";
    Console.WriteLine($"{entry.Key,-10} {average,6:F1} {grade}");
}
