Study routine: 20% reading → 50% typing and building → 20% debugging → 10% explanation. Each chapter has 4 guided lessons, 4 applied challenges, 2 quizzes, a developer interview question and a completion checklist.

Quick start

  1. Install the .NET 10 SDK and VS Code with C# Dev Kit (or Rider/Visual Studio).
  2. Open a terminal and check dotnet --version.
  3. Create a new practice folder and follow the first lesson.
  4. For each project, write at least five tests and save output proving your solution works.
Terminal
dotnet new console -n MyFirstCSApp
cd MyFirstCSApp
dotnet run

Important: the HTML quizzes run in your browser. The website is not a C# compiler; use the .NET SDK for actual execution and tests.
