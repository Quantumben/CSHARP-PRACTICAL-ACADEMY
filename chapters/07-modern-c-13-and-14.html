GUIDED LESSON 7.2

C# 13: params collections

C# 13 extends params beyond arrays to supported collection types. It enables more flexible APIs while preserving call-site convenience.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
static int Sum(params ReadOnlySpan<int> values)
{
    int total = 0;
    foreach (int n in values) total += n;
    return total;
}
Console.WriteLine(Sum(2, 4, 6));

GUIDED LESSON 7.3

C# 13: dedicated lock

When you need mutual exclusion, System.Threading.Lock provides dedicated lock semantics in supported targets. Keep critical sections short and do not await inside a lock.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
using System.Threading;
var gate = new Lock();
int count = 0;
lock (gate)
{
    count++;
}

GUIDED LESSON 7.4

C# 14: field-backed properties

The field contextual keyword accesses the compiler-generated backing field in an accessor. This avoids a manually declared field for simple validation, though names can conflict with existing identifiers.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
public class Contact
{
    public string Email
    {
        get;
        set => field = !string.IsNullOrWhiteSpace(value)
            ? value : throw new ArgumentException("Email required");
    } = "unknown@example.com";
}

C# 14: null-conditional assignment

A null-conditional assignment updates a member only when its receiver is non-null. This is particularly useful for optional objects.

Settings? settings = new();
settings?.Theme = "Dark";
Console.WriteLine(settings?.Theme);

GUIDED LESSON 7.6

C# 14: extension members

Extension blocks can define extension methods and properties. They make APIs discoverable but should not hide important domain behavior.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
public static class TextExtensions
{
    extension(string value)
    {
        public bool IsLong => value.Length > 10;
    }
}
Console.WriteLine("Programming".IsLong);
