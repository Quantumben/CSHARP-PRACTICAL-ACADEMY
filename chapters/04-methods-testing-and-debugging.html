MODULE 04 / Foundations

Methods, Testing, and Debugging

Organize code into focused, testable methods and observe failures. This module is built around a practical workplace scenario rather than memorizing syntax.

By the end you can: A merchant charges ₦1,500 base delivery, plus ₦400 per kilometer beyond 5 km. Write a pure method and tests.
Pass criteria: Distances cannot be negative; verify distances 0,5,6,12 with automated tests.

How to work through this module

  1. Read each concept; type the sample rather than simply copying it.
  2. Predict the output, run with dotnet run, and compare your prediction.
  3. Complete the guided modification, then the independent challenge without looking at hints.
  4. Debug failures, check edge cases, take the quizzes, and mark this module complete.

Laravel connection: C# uses explicit types and compiled projects. A C# method resembles a PHP method, ASP.NET routes serve a similar role to Laravel routes, EF Core parallels Eloquent conceptually, and dependency injection is built into ASP.NET Core.

GUIDED LESSON 4.1

Methods and return values

A method encapsulates behavior and should have one clear purpose. Use descriptive names and make inputs and outputs explicit.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
static decimal Total(decimal price, int quantity)
{
    ArgumentOutOfRangeException.ThrowIfNegative(quantity);
    return price * quantity;
}
Console.WriteLine(Total(25.5m, 3));
