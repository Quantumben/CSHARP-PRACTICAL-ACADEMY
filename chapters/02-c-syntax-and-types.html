MODULE 02 / Foundations

C# Syntax and Types

Discover values, declarations, string interpolation and type safety. This module is built around a practical workplace scenario rather than memorizing syntax.

By the end you can: An online shop sells a ₦12,500 training book; a buyer orders 3 and receives a 10% discount. Print subtotal, discount and grand total.
Pass criteria: Use decimal for all money, validate quantity greater than zero, format totals clearly.

How to work through this module

  1. Read each concept; type the sample rather than simply copying it.
  2. Predict the output, run with dotnet run, and compare your prediction.
  3. Complete the guided modification, then the independent challenge without looking at hints.
  4. Debug failures, check edge cases, take the quizzes, and mark this module complete.

Laravel connection: C# uses explicit types and compiled projects. A C# method resembles a PHP method, ASP.NET routes serve a similar role to Laravel routes, EF Core parallels Eloquent conceptually, and dependency injection is built into ASP.NET Core.

GUIDED LESSON 2.1

Statements and expressions

An expression evaluates to a value; a statement performs work. C# is case-sensitive and uses semicolons after most statements. Comments explain why code exists, not what obvious code does.

GUIDED LESSON 2.2

Types and inference

Use int for whole numbers, decimal for financial amounts, double for scientific measurements and string for text. var tells the compiler to infer a static type; it does not create a dynamically typed variable.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
var count = 3;           // int
decimal price = 19.95m;
string product = "Notebook";
Console.WriteLine($"{count} × {product}: {count * price:C}");

GUIDED LESSON 2.3

Conversions

C# distinguishes safe implicit conversions from explicit casts. For untrusted input, TryParse is usually preferable to Parse, which can throw.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
string input = "42";
if (int.TryParse(input, out int number))
{
    Console.WriteLine(number * 2);
}

GUIDED LESSON 2.4

Strings and formatting

Interpolated strings combine text and expressions; verbatim and raw string literals help with multiline text. Prefer culture-aware formatting for values intended for people.
