GUIDED LESSON 13.3

Dependency injection

The built-in DI container manages service lifetimes. Scoped services are appropriate for request-related work; avoid capturing scoped services in singleton services.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddScoped<TimeService>();
var app = builder.Build();
app.MapGet("/time", (TimeService clock) => clock.Now);
app.Run();
public class TimeService
{
    public DateTimeOffset Now => DateTimeOffset.UtcNow;
}

GUIDED LESSON 13.4

Middleware and security

Middleware order affects routing, authentication, authorization, CORS and error handling. Enable HTTPS, validate requests, and use explicit authorization policies for protected resources.

var app = builder.Build();
