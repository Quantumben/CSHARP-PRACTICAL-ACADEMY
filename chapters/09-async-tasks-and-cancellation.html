GUIDED LESSON 9.1

Asynchronous programming

async/await allows non-blocking waiting, especially for I/O. It does not guarantee a separate thread; avoid Task.Run just to make already async I/O appear asynchronous.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#

{
    await Task.Delay(200);
    return "Completed";
}

GUIDED LESSON 9.2

Cancellation and timeouts

Pass CancellationToken through long-running operations. Expect OperationCanceledException when a request is canceled and ensure resources are disposed.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(2));
try
{
    await Task.Delay(TimeSpan.FromSeconds(5), cts.Token);
}
catch (OperationCanceledException)
{
    Console.WriteLine("Cancelled");
}

GUIDED LESSON 9.3

Parallel coordination

Task.WhenAll waits for several operations to complete. Concurrency is not the same as CPU parallelism; consider service limits, memory and failure behavior.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
Task<int> a = Task.FromResult(10);
Task<int> b = Task.FromResult(20);
int[] values = await Task.WhenAll(a, b);
Console.WriteLine(values.Sum());

GUIDED LESSON 9.4

Async streams

IAsyncEnumerable<T> represents a sequence produced asynchronously, which is useful for paginated APIs and streaming data.

Step 1 · Read and predict

Before running the example, underline all new keywords. Write down the output you expect or the change you expect it to make.

C#
static async IAsyncEnumerable<int> CountAsync()
{
    for (int i = 1; i <= 3; i++)
    {
        await Task.Delay(100);
        yield return i;
    }
}
await foreach (int number in CountAsync()) Console.WriteLine(number);
